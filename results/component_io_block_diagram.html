🧬 Step-by-Step Component Input/Output Architecture

Exact data structures, matrix dimensions, algorithms, and intermediate files produced at every stage of the pipeline

Step 01
📥 Data Ingestion & Input Verification 01_ingest_patient_data.py
📥 Input Data
  • sample_patients.csv
  • Clinical features (Age, Sex, Stage, TMB)
  • RNA-Seq gene expressions (Top 300 genes)
Matrix: [N x 305] DataFrame
⚙️ Processing Logic
  • Load raw patient records
  • Validate column presence & data types
  • Separate clinical vs expression features
Validation: Zero Missing Values
📤 Output File
  • step01_ingested_data.pkl
  • Structured patient dictionary
  • Patient IDs list
Saved File: PKL artifact
⬇️
Step 02
🛠️ Feature Preprocessing & PCA Dimensionality Reduction 02_feature_transformation.py
📥 Input Data
  • step01_ingested_data.pkl
  • Clinical sub-matrix [N x 4]
  • Gene expression matrix [N x 300]
Raw Features
⚙️ Processing Logic
  • Clinical: Impute + OHE + StandardScaler
  • Genomic: log₂(x+1) + Gram-Schmidt filter
  • PCA Compression: 300 genes → 50 PCs
V: Loadings [300 x 50]
📤 Output File
  • step02_transformed_features.pkl
  • Xclin: [N x 9] preprocessed matrix
  • Xpca: [N x 50] component matrix
Combined X: [N x 59]
⬇️
Step 03
⚙️ Cox Elastic-Net Log-Hazard Risk Scoring 03_cox_risk_scoring.py
📥 Input Data
  • step02_transformed_features.pkl
  • Transformed matrix X [N x 59]
  • Locked Cox coefficients β [59 x 1]
Feature Matrix + Weights
⚙️ Processing Logic
  • Linear matrix multiplication
  • ηi = Xi,clin βclin + Xi,pca βpca
  • Clip risk range to [-40, 40]
Formula: η = X · β
📤 Output File
  • step03_risk_scores.json
  • Log-hazard risk score (η) per patient
  • Risk percentile ranking vs TCGA cohort
Vector: η [N x 1]
⬇️
Step 04
📊 Isotonic Survival Probability Calibration 04_isotonic_calibration.py
📥 Input Data
  • step03_risk_scores.json
  • Risk score vector η [N x 1]
  • Fitted Isotonic calibrators (PAVA)
Risk Score Vector
⚙️ Processing Logic
  • Non-parametric PAVA step-mapping
  • Map η → P(Event > t)
  • Evaluate at 12m, 24m, 36m, 60m
Monotonic Mapping
📤 Output File
  • step04_calibrated_probabilities.json
  • P(S > 12m), P(S > 24m)
  • P(S > 36m), P(S > 60m)
Matrix: [N x 4] Probabilities
⬇️
Step 05
🎲 Monte Carlo Stochastic Survival Simulation 05_monte_carlo_simulation.py
📥 Input Data
  • step03_risk_scores.json
  • Baseline Cumulative Hazard Λ₀(t)
  • 5,000 Uniform draws U(k) ~ (0,1)
Baseline Hazard + Seed
⚙️ Processing Logic
  • Λtarget(k) = -ln(U(k)) / exp(ηi)
  • Invert step hazard: t(k) = Λ₀⁻¹(Λtarget)
  • Extract 10th, 50th, 90th percentiles
Inverse Transform Sampling
📤 Output File
  • step05_monte_carlo_bounds.json
  • P10 (Pessimistic), P50 (Median)
  • P90 (Optimistic), RMST (60m)
Quantiles Matrix: [N x 4]
⬇️
Step 06
🔍 PCA Back-Projection & Local XAI Waterfall 06_xai_explainability.py
📥 Input Data
  • Raw expression Zgene [N x 300]
  • PCA Loadings V [300 x 50]
  • PCA Weights βpca [50 x 1]
Loadings + Patient Expression
⚙️ Processing Logic
  • Wgene = V · βpca (Global gene weights)
  • Δηg,i = Zg,i · Wgene,g (Patient impact)
  • Rank top risk & protective drivers
Linear Matrix Unrolling
📤 Output File
  • step06_patient_explainability.json
  • Top 5 risk-increasing genes
  • Top 5 protective genes
Waterfall Breakdown
⬇️
Step 07
📋 Master Aggregator & Clinical Dossier Generation 07_generate_final_dossier.py
📥 Input Sources
  • step03_risk_scores.json
  • step04_calibrated_probs.json
  • step05_monte_carlo.json
  • step06_explainability.json
⚙️ Merging Logic
  • Join by PATIENT_ID
  • Format clinical survival tables
  • Generate patient waterfall plots
📤 Final Output Deliverables
  • step07_final_dossier.csv
  • step07_final_dossier.json
  • Console summary dashboard
